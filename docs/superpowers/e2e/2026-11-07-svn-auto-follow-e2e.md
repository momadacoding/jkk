**对应分支：`worktree-feat-svn-auto-follow`。** 配套计划 `docs/superpowers/plans/2026-11-06-svn-auto-follow.md`

## 这一期验的是什么

TortoiseSVN 提交或更新之后，切回 jkk（钩子注册过的话不用切），不用点任何按钮：

- 条件都满足时，基线与分支自动跟上，横幅区最上面出现一条灰色提示「已自动跟进 SVN 侧的新内容」，
  「查看详情」打开与手动跟进相同的报告，「知道了」关掉；
- 条件不满足时什么都不动，「SVN 侧有 N 个文件有新内容」横幅上多一行「没有自动跟进：……」，写明是哪一条，
  「跟进」按钮照旧；
- 设置里可以关掉，关掉后回到只挂横幅；
- 全程不写工作区里的文件。

新增的 Tauri 命令 `svn_follow_auto(path)`、`set_svn_auto_follow(enabled)`，`read_app_settings` 多了
`svnAutoFollow` 字段。参数名的 `snake_case` ↔ `camelCase` 转换没有编译期检查（`AGENTS.md` §7.3），
场景 1 与场景 6 走通就说明两条命令接对了。

## 场景

### 场景 1：只提交、不更新

1. 在白名单里改两个文件 A、B，只在 TortoiseSVN 里提交 A。
2. 切回 jkk。
3. **期望**：几秒内横幅区最上面出现「已自动跟进 SVN 侧的新内容」，「本地改动」里只剩 B；
   点「查看详情」，报告「跟进的文件」里有 A；点「知道了」提示消失。磁盘上的 A、B 没被改过（TortoiseSVN 里 B 仍是已修改）。

### 场景 2：同事的改动，局部更新

1. 让同事（或另一份工作副本）改文件 C 并提交。
2. 在 TortoiseSVN 里只对 C 做「更新」，切回 jkk。
3. **期望**：自动跟进，「本地改动」里没有 C，报告里 C 的作者是同事。

### 场景 3：分支上的 commit 碰到同一个文件

1. 在 jkk 里改 D 的第一行并提交（git commit）。
2. 同事改 D 的最后一行并提交；你在 TortoiseSVN 里对 D 更新（不冲突）。
3. 切回 jkk。
4. **期望**：没有自动跟进的提示；「SVN 侧有新内容」横幅上有一行「没有自动跟进：当前分支上的提交改过的文件，SVN 侧也有新内容（D）……」。
   点「跟进」完成，D 在分支里两处改动都在。

### 场景 4：重放冲突

1. 在 jkk 里把 E 改成 e2 并提交；再在磁盘上改成 e3，用 TortoiseSVN 提交（没有失焦快照时会冲突）。
2. 切回 jkk。
3. **期望**：横幅写明「当前分支的提交重放到新基线上有冲突（E）」；提交图里 `svn/base` 没动。点「跟进」弹出冲突框。

### 场景 5：连不上服务器

1. 改 F，用 TortoiseSVN 提交（提交要联网）。**在切回 jkk 之前**断开网络（拔网线 / 断 VPN）。
   注册了钩子的话先在钩子框里撤销注册，否则提交一完成 jkk 就跟进了。
2. 切回 jkk。
3. **期望**：横幅写明「这次没能向服务器核对新基线」；什么都没动。恢复网络后点「跟进」完成。

### 场景 6：设置开关

1. 设置 → 取消勾选「TortoiseSVN 提交或更新之后自动跟进」→ 保存。
2. 改 G 并用 TortoiseSVN 提交，切回 jkk。
3. **期望**：只有「SVN 侧有新内容」横幅，没有「没有自动跟进」那一行，也没有自动跟进的提示。
4. 重新勾上、保存；改 H 并提交，切回 jkk：自动跟进。

### 场景 7：钩子即时触发

前提：顶部「TortoiseSVN 钩子…」里已注册。

1. 改 I，用 TortoiseSVN 提交，**不要**切回 jkk（把 jkk 窗口放在旁边看着）。
2. **期望**：提交完几秒内 jkk 里出现自动跟进的提示。

### 场景 8：部分自动跟进（计划 2026-11-13-partial-auto-follow）

1. 照场景 3 做出 D：分支上的 commit 改过、SVN 上也有新内容，再在磁盘上给 D 加一行**不提交**（让重放结果和磁盘对不上）。
2. 另改 J，用 TortoiseSVN 提交。切回 jkk。
3. **期望**：出现「已自动跟进 SVN 侧的新内容」，提示是要人看的颜色，写着「1 个文件留在旧基线上」；「查看详情」里
   「留在旧基线上的文件」列出 D 和原因（重放出来的结果和磁盘对不上），「跟进的文件」里有 J、没有 D。
   提示下面的「SVN 侧有新内容」横幅只剩 D，原因行和场景 3 一样。磁盘上的 D、J 都没被改过。
4. 对照：把 J 换成**新增**的文件、D 换成 SVN 上新增的文件出问题（例如 Local-Only 提交加的新文件被 `svn add` 提交了），
   整次不做，横幅原因和以前一样。
