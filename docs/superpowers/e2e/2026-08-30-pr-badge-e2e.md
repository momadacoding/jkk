## 复现方式

需要一个满足以下条件的仓库才能看到全部三种形态：

1. GitHub 托管，本机 `gh auth status` 已登录
2. 至少一条本地分支有 open PR（非 draft）
3. 至少一条本地分支有 draft PR
4. 至少一条本地分支的 PR 已 merged 但分支未删（squash 合并后的常见残留）

本仓库当前满足 3 和 4；**条件 2（open 非 draft）的真机形态尚未拍到**，第 9 项的计算
覆盖是它目前唯一的保障。把 PR #37 从 draft 转为 ready 即可补上这一项。
