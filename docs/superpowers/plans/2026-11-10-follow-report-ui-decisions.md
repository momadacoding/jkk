## 决策

### D1 只做一个方案，不出菜单

考虑过：A 只调样式（颜色、字体）；B 模型加分级 + 弹框分区（本方案）；C 改成左侧目录 + 右侧详情的双栏。
A 解决不了「标题不说结果」和「排序与轻重不符」，这两条是模型层的问题；C 在 800px 宽的默认窗口里两栏都太窄，路径要折好几行。选 B。

### D2 三级轻重取代 `warn: boolean`（偏离原模型）

`FollowReportSection.warn` 换成 `level: 'danger' | 'attention' | 'info'`：

- `danger`（红）：分支与磁盘对不上、泄漏告警、丢失的暂存、没向服务器体检过——不处理会出错或已经丢了东西
- `attention`（琥珀）：拿不准的暂存、快照内容、落后的分支——要你确认一下
- `info`（灰）：其余

节按 `level` 稳定排序（同级保持书写顺序），以后加候选写错位置也不会排到文件清单后面。
`tone` 由 `level` 推出（`ok` 以外都是 `attention`），不再单独算。

### D3 标题写出要处理几项

全部顺利时仍是「跟进完成」；有 danger 时「跟进完成，有 N 项需要处理」，只有 attention 时「跟进完成，有 N 项请确认」。N 是非 info 的节数。自动跟进横幅的详情同样写出 N。

### D4 清单条目结构化

`items: string[]` 换成 `{ text, meta?, more? }[]`：路径（或分支名、commit）是 `text`，revision、所在分支与提交说明、落后原因是 `meta`，右对齐、灰色、非等宽；「…还有 N 个」是 `more`。每节带 `count`，是截断前的真实条数。

### D5 折叠规则

需要留意的节永远展开；info 节在 8 条以内展开，超过就折起来、只露标题和条数。整框只有 `.dialog` 自己一个滚动区，去掉报告区的 `max-height`，长报告不再出两条滚动条。

折叠用 `<details>`，但开合由 React state 管（`summary` 的 click 里 `preventDefault`），折起来时正文**不渲染**，`summary` 带 `tabIndex={0}`。理由见 review 第 1、2 条。

### D6 「判定依据」和 SVN 用户名挪到页脚

两者是同一件事（暂存 / commit 归属按什么判），而且都不是这次跟进的结果。挪到分隔线下面的页脚，用户名一行改成「标签 + 一句话用途 + 输入框 + 按钮」，按钮与弹框按钮同一套样式，输入框给出占位示例。

### D7 每节先列一部分（第一版截图后补的）

第一版只靠折叠：长报告里 100 条的「分支与磁盘对不上」全部铺开，后面的节和页脚要滚很久。改成预览：只有一组时列前 10 条，
有多组时每组列前 5 条（每组的小标题都露出来）。下面一个「再显示 N 个」，N 是展开后真能多看到的条数，不含 engine 截掉的部分；展开后可以「收起」。

### D8 「没向服务器体检」是一节，不再是 `warning` 字段

原来 engine 给一个 `warning` 字符串、组件里手搭一张卡片，项数却在 engine 里 +1，两边要手工对齐。改成 engine 出一节
`id: 'unverified'`（danger、`count: 0`、没有清单），排在最前；`FollowReportModel.warning` 删掉。

## 计划没写的坑

- 「知道了」贴在框底（sticky），打开时 `focus()` 会把整个框滚到最底下，摘要和要处理的事都在视野外。
  旧版本报告区自己限高，框不够长，所以没暴露。改成 `focus({ preventScroll: true })`。
- `useFocusTrap` 按选择器挑 Tab 的落点，不认 `<summary>`，也不管元素在不在关着的 `<details>` 里：
  藏着的按钮会被挑中、`focus()` 落不上，Tab 卡在原地。没改共用的 hook（所有弹框都挂它），在本组件里规避。
- RTL 的 `getByText` 只认元素自己的文本节点：路径和 revision 拆成两个 `<span>` 之后，`/Code\/A\.cs\s+r7/` 匹配不到，测试改成比对 `<li>` 里 `.follow-meta` 的文本。

## 为什么这么改是安全的

只动展示层：`FollowReport`（后端契约）、`describeFollowOutcome`（冲突框）、Tauri 命令一个都没碰，不涉及任何 git 写操作。

`tone` 与原判定的差别只有一处：后端给出 `snapshot` 里某个 commit 的路径清单为空（`[commit, []]`）时，原来会变黄，现在不变。
这种条目在报告里什么都显示不出来，变黄只会让人找不到要看什么，所以不算回归（review 第 7 条）。
